Kindling is a Kotlin multi-module library for Jetpack Compose. The components are modelled on
[shadcn/ui](https://ui.shadcn.com): small, composable, and fully theme-aware through Material3.
Every component reads its colours from `MaterialTheme.colorScheme`, so light and dark schemes work out of the box.

## How these docs are made

The API reference pages are generated from the KDoc comments in the source code, so they stay in sync with the library.
Hand-written pages (like this one) live next to them, and previews are rendered live by a Compose for Web app.
See [Contributing to the docs](/docs/contributing-docs) for how to regenerate, edit or AI-draft a page.
