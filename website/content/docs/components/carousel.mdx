Arrows are `KButton` instances rendered beside the pager (not overlaid).

```kotlin
val api = rememberCarouselApi(pageCount = items.size)
KCarousel(api = api) {
    KCarouselContent {
        items.forEach { item ->
            KCarouselItem { MySlide(item) }
        }
    }
}
// Anywhere:
Text("Slide ${api.currentSlide + 1} /${api.slideCount}")
```

## Types

### KCarouselApi

Public state exposed by `KCarousel` — mirrors the web `CarouselApi`.

Access via `rememberCarouselApi()` and pass to `KCarousel`.

```kotlin
class KCarouselApi
```

**Members**

- `val currentSlide: Int get()` — Zero-based index of the currently visible slide.
- `val slideCount: Int get()` — Total number of slides.
- `val canScrollPrev: Boolean get()` — Whether the user can scroll to the previous slide.
- `val canScrollNext: Boolean get()` — Whether the user can scroll to the next slide.
