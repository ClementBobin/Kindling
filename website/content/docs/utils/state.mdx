Port of the `useStateWithHistory` and `useUndoRedo` React hooks.

```kotlin
val history = StateWithHistory("hello", capacity = 10)

history.set("world")
history.set("!")

history.back()             // → "world"
history.forward()          // → "!"

println(history.canUndo)   // true
println(history.canRedo)   // false

// Observe reactively:
history.state.collect { v -> println(v) }
```

## Usage

```kotlin
val log = KCircularBuffer<String>(capacity = 3)
log.add("a")  // Buffer: [a]
log.add("b")  // Buffer: [a, b]
log.add("c")  // Buffer: [a, b, c]
log.add("d")  // Buffer: [b, c, d]  ← "a" is automatically dropped

println(log.toList()) // Prints: [b, c, d]
println(log.latest()) // Prints: "d"

// In a Composable:
val items by log.state.collectAsState()
LazyColumn {
    items(items) { Text(it) }
}
```

### KCircularBuffer

A fixed-capacity ring buffer (Circular Buffer).

When the buffer is full, adding a new item silently drops the **oldest** entry.
This implementation is ideal for bounded logs, recent-search history, rolling telemetry windows,
or any scenario where you only need to keep the last `N` items.

The buffer state is exposed as a `StateFlow`, making it easy to observe changes in a reactive UI.

```kotlin
class KCircularBuffer<T>(val capacity: Int)
```

<TypeTable type={{"capacity":{"type":"Int","description":"The maximum number of items the buffer can retain. Must be ≥ 1.","required":true}}} />

**Members**

- `val state: StateFlow<List<T>>` — Snapshot of all items as a `StateFlow` (oldest → newest). Emits on every structural change.
- `val size: Int get()` — Number of items currently in the buffer.
- `val isFull: Boolean get()` — `true` when the buffer is at full `capacity`.
- `val isEmpty: Boolean get()` — `true` when the buffer contains no items.
- `fun add(item: T)` — Adds `item` to the buffer. If the buffer is full, the oldest item is removed first.
- `fun addAll(items: Iterable<T>)` — Adds all `items` in order, dropping oldest entries as needed to stay within `capacity`.
- `fun latest(): T?` — Returns the most recently added item, or `null` if empty.
- `fun oldest(): T?` — Returns the oldest item currently in the buffer, or `null` if empty.
- `fun toList(): List<T>` — Returns a snapshot list ordered oldest → newest.
- `fun remove(item: T)` — remove a single item from the buffer.
- `fun clear()` — Removes all items from the buffer.

### KTimer

Port of the `useTimeout` React hook.

### KInterval
