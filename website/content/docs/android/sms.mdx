### SmsHelper

Helper SMS centralisé.

Deux modes :
- **Envoi direct** (`send`) — nécessite `SEND_SMS`, envoie sans UI.
- **Composeur SMS** (`openComposer`) — ouvre l'app SMS, aucune permission.

Enregistrement Koin :
```kotlin
single { SmsHelper(androidContext()) }
```

Utilisation :
```kotlin
// Ouvrir le composeur (pas de permission)
smsHelper.openComposer(SmsConfig.simple("+33612345678", "Bonjour !"))

// Envoi direct (SEND_SMS requis)
smsHelper.send(SmsConfig.otp("+33612345678", "849201"))
```

**Members**

- `fun send(config: SmsConfig)` — Envoie le SMS décrit par `config` directement, sans UI. Requiert `SEND_SMS`.
- `fun openComposer(config: SmsConfig)` — Ouvre l'app SMS par défaut avec le numéro et le corps pré-remplis. Aucune permission requise. Si aucune app SMS n'est disponible, attrape `ActivityNotFoundException` et journalise l'erreur sans planter.
- `fun openComposer(phoneNumber: String)` — Ouvre le composeur avec un numéro uniquement.
