### ClipboardHelper

Helper presse-papiers centralisé.

Enregistrement Koin :
```kotlin
single { ClipboardHelper(androidContext()) }
```

Utilisation :
```kotlin
clipboardHelper.copy(ClipboardContent.plainText("hello"))
clipboardHelper.copy("https://kindling.dev")  // label générique "text"
val text = clipboardHelper.paste()   // null si vide ou non-texte
clipboardHelper.clear()              // API 28+ seulement, no-op sinon
```

**Members**

- `fun copy(content: ClipboardContent)` — Copie `content` dans le presse-papiers.
- `fun copy(text: String)`
- `fun paste(): String?` — Lit le texte courant du presse-papiers. Retourne `null` si vide, non-texte, ou accès refusé (API 29+ background).
- `fun clear()` — Vide le presse-papiers (API 28+, no-op sur les versions antérieures).
- `fun hasText(): Boolean` — `true` si le presse-papiers contient du texte accessible.
