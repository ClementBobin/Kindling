### PermissionHelper

Helper de permissions centralisé.

Deux modes d'utilisation :

**1. Vérification synchrone** (sans Activity) :
```kotlin
val status = permissionHelper.check(PermissionRequest.Camera)
```

**2. Demande runtime** (nécessite une `FragmentActivity`) :
```kotlin
// Dans onCreate ou onStart :
val launcher = permissionHelper.registerLauncher(activity) { results ->
    results.forEach { (permission, status) -> /* … */ }
}

// Déclenchement — le callback est toujours invoqué, même si tout est déjà accordé :
permissionHelper.request(PermissionRequest.Camera, launcher)
```

Enregistrement Koin :
```kotlin
single { PermissionHelper(androidContext()) }
```

**Members**

- `fun check(request: PermissionRequest): PermissionStatus` — Vérifie le statut d'une `PermissionRequest` sans déclencher de dialogue. Pour une request multi-permissions, retourne `PermissionStatus.Granted` seulement si toutes les permissions sont accordées.
- `fun isGranted(request: PermissionRequest): Boolean` — `true` si toutes les permissions du `request` sont accordées.
- `fun registerLauncher( activity: FragmentActivity, onResult: (Map<String, PermissionStatus>) -> Unit): ActivityResultLauncher<Array<String>>` — Enregistre un launcher de permission à partir d'une `FragmentActivity`. À appeler dans `onCreate` ou `onStart`, avant que l'Activity soit started.
- `fun request( request: PermissionRequest, launcher: ActivityResultLauncher<Array<String>>, onAllGranted: () -> Unit = {})` — Déclenche la demande pour le `request` via le `launcher` fourni. Les permissions déjà accordées sont filtrées et ne déclenchent pas de dialogue.
- `fun openAppSettings(context: Context)` — Ouvre les réglages de l'app — utile après un `PermissionStatus.PermanentlyDenied`.
