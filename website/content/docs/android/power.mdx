### WakeLockConfig

Décrit un WakeLock à acquérir.

Presets :
- `WakeLockConfig`  → CPU actif, écran peut s'éteindre (background work)
- `WakeLockConfig`    → Écran allumé en mode dim (déprécié API 17, préférer FLAG_KEEP_SCREEN_ON dans l'UI)
- `WakeLockConfig` → Écran pleine luminosité (déprécié API 17)

Remarque : Pour maintenir l'écran allumé (dim/bright), utiliser FLAG_KEEP_SCREEN_ON 
au niveau de l'Activity / View au lieu de PowerManager. WakeLock.
