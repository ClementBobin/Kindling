# Security Policy

Thank you for helping improve the security of this project.

## Supported Versions

Security updates are provided for the latest stable release.

| Version | Supported |
| ------- | :-------: |
| Latest release | ✅ |
| Older releases | ❌ |

If you're using an older version, please upgrade to the latest release before reporting a security issue.

### What to Include

Please include as much information as possible:

- A description of the vulnerability
- Steps to reproduce the issue
- A proof of concept (if available)
- The affected version(s)
- Potential impact

### Response Timeline

You can expect:

- **Status updates:** As progress is made
- **Resolution:** A fix will be released as soon as reasonably possible after the issue has been verified.

### Disclosure Policy

Please allow time for the vulnerability to be investigated and, if necessary, fixed before publicly disclosing it.

We appreciate responsible disclosure and will work with you to resolve valid security issues promptly.

Thank you for helping keep this project and its users secure.
