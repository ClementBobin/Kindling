# Contributing

Thank you for considering a contribution!

## Build locally

```bash
./gradlew build
```

## Run tests

```bash
./gradlew test
```

## Branch naming convention

- `feat/<short-description>`
- `fix/<short-description>`
- `chore/<short-description>`

## Pull Request checklist

- [ ] Tests pass locally
- [ ] Changelog updated
- [ ] Documentation updated when needed
